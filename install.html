Install on iPhone

  1. Tap Share in Safari's toolbar. In Chrome it's at the top right.
  2. Scroll down and tap Add to Home Screen
  3. Tap Add. Open Log Studio from your home screen.

Install from the browser menu

  1. Open this page in Chrome (or Edge / Samsung Internet).
  2. Tap the menu ⋮, then Install app or Add to Home screen.
Use it in the browser instead Open the app once while online. After that it starts offline from your home screen.
